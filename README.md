# POTA スポットパネル

POTA（Parks on the Air）のスポット情報を、Chrome の右側のサイドパネルに表示する拡張機能です。
ほかのページを見ながら、POTA のスポットを確認できます。

## できること
- 1 分ごとに自動で更新（「今すぐ更新」ですぐに取り直せます）
- 「日本の局だけ表示」（初期設定はオン）
- モードの絞り込み（CW / SSB / FM / AM / FT8 / FT4 / RTTY / DATA / その他）
- 周波数帯の絞り込み（160m / 80m / 40m / 30m / 20m / 17m / 15m / 12m / 10m / 6m / 2m / 70cm / その他）
- 「未交信の公園だけ表示」（POTA のサイトからダウンロードしたハンターの交信ログ（CSV）を読み込んで判定）
- 新しいスポットが出たら通知音を鳴らし、黄色で表示
- 公園番号を押すと、pota.app の公園のページを開く
- 設定は次回も残ります

## 入れ方
1. このページの右側の **Releases** から、最新の `pota-spot-panel-x.y.z.zip` をダウンロードします。
2. zip を右クリック →「すべて展開」で展開します。展開したフォルダは、消さずに置いておいてください。
3. Chrome のアドレス欄に `chrome://extensions` と入力して開きます。
4. 右上の **「デベロッパー モード」** をオンにします。
5. **「パッケージ化されていない拡張機能を読み込む」** を押し、展開したフォルダ（`manifest.json` が入っているフォルダ）を選びます。
6. アドレス欄の右のパズルのアイコン →「POTA スポットパネル」の **ピン** を押すと、木のアイコンが常に表示されます。

## 使い方
- 木のアイコンを押すと、右側にサイドパネルが開きます。
- 通知音が鳴らないときは、パネルを一度クリックしてください。「モードの絞り込み」の中の「音のテスト」で確認できます。
- パネルを閉じている間は更新しません（開くとすぐに最新を取得します）。

### 未交信の公園だけ表示
1. pota.app にログインし、ハンターの交信ログ（CSV）をダウンロードします。
2. パネルの「交信ログ（CSV）」を開き、そのファイルを選びます。
3. 「未交信の公園だけ表示」にチェックを入れます。

ログを読み込むと、各スポットに「交信済」「未交信」の印も付きます。新しく交信したら、ログをダウンロードし直して読み込み直してください。

## 新しい版に更新するとき
新しい zip をダウンロードして展開し、前のフォルダの中身と入れ替えてから、`chrome://extensions` で「POTA スポットパネル」の **更新ボタン（くるっと回る矢印）** を押してください。

## データの扱い
- スポット情報は POTA の公開 API（`https://api.pota.app/spot/activator`）から取得します。ほかの場所とは通信しません。
- 設定は Chrome の中（`chrome.storage.local`）にだけ保存します。Google アカウントへの同期はしません。
- 交信ログ（CSV）はパソコンの中だけで読みます。保存するのは、中から拾った公園番号とファイル名・読み込んだ日時だけで、
  交信相手や日時などログの中身は保存せず、外部にも送りません。パネルの「読み込んだログを消す」で消せます。
- 開いているほかのページの中身は読みません。
